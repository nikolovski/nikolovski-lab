# nikolovski-lab

Every skill and agent in the Nikolovski Lab as one plugin.

## Install (Claude Code)

```
/plugin marketplace add nikolovski/nikolovski-lab
/plugin install nikolovski-lab@nikolovski-lab
```

In the Claude app, add `nikolovski/nikolovski-lab` as a plugin marketplace, then install `nikolovski-lab`.

## What's in it

| Skill | What it does |
| --- | --- |
| [architecture-review](../../skills/architecture-review/SKILL.md) | Evidence-based review of a codebase or design: scorecard, ranked findings and a roadmap. |
| [improve-prompt](../../skills/improve-prompt/SKILL.md) | Rewrites a vague prompt into a clear, complete one for any AI tool. |

## How it's built

`skills/` and `agents/` at the repo root are the source of truth. The copies in this folder are generated by `npm run sync:plugins`, which copies every skill and every agent here. `npm run validate` fails when a copy is missing or out of step, so never edit the copies by hand.
